# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A single-page marketing site for **JEO BRAINS** (AI for interactive geojournalism in WordPress). It is a faithful reproduction of the approved **Figma** design — the source of truth for layout, spacing, and the canonical **PT-BR copy**. When changing text or layout, match the design rather than inventing content.

The current approved layout is **V2**, rendered to `figma-ref/desktop-v2.png` (1920×7463) from the Figma frame `JEO IA` (file `Vg86o3oBCO0BhTPh7PbduL`, node `187:708`), accessed via the Figma MCP server (Framelink: `get_figma_data` / `download_figma_images`). The older `desktop.png` (1920×6576) is the superseded V1 — prefer `figma-ref/desktop-v2.png`. To pull fresh frames/assets, reconnect the Figma MCP and re-fetch by file key + node id.

The app lives in `www/`. All commands below run from there.

## Commands

```bash
cd www
npm install
npm run dev      # Vite dev server (http://localhost:5173)
npm run build    # production build → dist/
npm run preview  # serve the production build
```

There is **no test runner and no linter configured** — don't reference `npm test`/`npm run lint`. Verify changes by building and visually checking in the browser.

## Stack

React 18 + Vite 5, Tailwind CSS 3 (classic config + PostCSS), Framer Motion (animation), lucide-react (icons). The whole page uses **Open Sans** (matching Figma) for both `display` and `sans` — loaded via Google Fonts `<link>` in `index.html` as the variable font **with the width axis** (`Open+Sans:wdth,wght@75..100,300..800`; `font-black`/900 falls back to 800, which Open Sans tops out at). Several Figma headings are **Open Sans Condensed**: apply the `.font-condensed` utility (defined in `index.css` as `font-stretch: 75%`, which maps to the wdth axis) — currently on the WhySection main heading + its `→ TITLE` rows, the Recursos heading, the WordPress heading + "PASSO N" labels, the ReadySection heading, and the Transparência heading. Archivo/Inter are gone.

## Architecture

- **`src/App.jsx`** composes the page: it renders the section components in fixed top-to-bottom order plus the global UI — a scroll-progress bar (`useScroll`/`useSpring`) and the fixed `Header`. To reorder or add a section, edit the JSX here.
- **`src/components/Header.jsx`** is a fixed top bar (logo + nav + "Install free") that stays hidden and slides down once the page scrolls past ~50% of the hero (`scrollY > innerHeight * 0.5`). `index.css` sets `scroll-padding-top` so anchor jumps clear it. The nav links (Brains→`#top`, Theme→`#recursos`, Plugin→`#integracao`) have a **hover underline** and a **scroll-spy active state**: the same scroll handler sets `activeId` to the last section whose top is within 140px of the viewport top, and the matching link gets `aria-current` + a full-width teal underline. On **mobile** the links collapse into a **hamburger menu** (`Menu`/`X` toggle, `sm:hidden`) that animates open with the same links + Install free; tapping a link closes it and the anchor scroll still works.
- **`src/links.js`** centralizes the external destinations reused across sections — `DOWNLOAD_URL` (the GitHub branch `.zip`, used by every "Download"/"Install free" button), `DOCS_URL` (`jeowp.org/docs/`), and `GITHUB_URL` (the repo tree). All external links open in a new tab (`target="_blank" rel="noopener noreferrer"`). The five Recursos cards link to per-feature docs (in `FEATURES[].docUrl`).
- **`src/components/ConsentBanner.jsx`** (rendered last in `App.jsx`) is a discrete bottom-left cookie/terms popup shown only on first visit; "Aceitar" writes `localStorage['jeo-consent-v1'] = 'accepted'` so it never reappears. The **footer "Termos de uso e privacidade"** is a button opening a terms modal (content is placeholder PT-BR text defined in `Footer.jsx`).
- **One component per section** in `src/components/` (Hero, WhySection, FeaturesSection, WordPressSection, ReadySection, NewsletterSection, WorkshopsSection, TransparencySection, Footer). Section content (feature cards, steps, workshops) is defined as plain data arrays at the top of each file and mapped into markup — edit copy there.
- **`src/components/ui/`** holds reusable primitives. `Reveal.jsx` is the shared scroll-in animation wrapper used by nearly every section — prefer wrapping new content in `<Reveal>` for consistent entrance behavior. `JeoMark` is the official brand "J" pillar mark (inlined SVG from Figma node 208:407, white strokes); `WordPressIcon` is a code-drawn WP glyph. `ParallaxImage.jsx` powers the pointer-reactive bg **in Recursos (`FeaturesSection`) only** — the Hero now uses a looping video instead (see below). It renders an image that drifts opposite the cursor (parallax) plus a softer-spring, blurred afterimage whose opacity is driven by pointer velocity — so a faint "trail" only fades in while the mouse is moving. Both layers are scaled up enough that the parallax offset never reveals edges; under reduced motion only the static main image renders.

### Two conventions worth knowing before editing

1. **Branded visuals are real assets extracted from Figma; only the J mark and WP glyph are code.** Raster assets live in `src/assets/`: `hero-bg.jpg` (now the hero video **poster**), `features-bg.jpg` (faint texture behind Recursos, used at ~7% opacity), `editor-print.png` (Gutenberg screenshot in the "Tudo pronto" section), and the footer partner logos `infoamazonia.png` / `codesinfo.png`. Two videos also live there: `hero-background.mp4` (hero background, ~9 MB, autoplays on load) and `print-animado.mp4` (~22 MB, only fetched when the "Tudo pronto" modal opens). Three **logotype SVGs exported straight from Figma** (text outlined to paths, so faithful without the font): `jeo-brains-wordmark.svg` (the hero "JEO BRAINS" logotype, node 187:777), `jeo-wordmark.svg` (the short "JEO" logotype used in the **Header and Footer** next to the `JeoMark` J pillar — node `I187:768;55:239`; it replaced the live "JEO" text), and `hacklab-logo.svg` (the footer "hacklab/" logo, node `I187:710;108:565`). Note: the Figma export tool reports `0x0` for these but **does write valid file content** — don't assume a failed export from the dimension line. **`src/assets/icons/` holds Figma-exported SVG icons** (teal, colors baked in — these instance exports came out correct, unlike the earlier component-definition exports): the five Recursos card icons `recursos-{geoloc,minimapa,leia-tambem,contexto,historias}.svg` (nodes 227:368/375/379/383/387, in card order — composite pin/map/etc. + a small teal "AI" badge) and the three Transparência button icons `trans-{github,docs,privacy}.svg` (nodes 227:392/395/401, in button order). All imported as ES modules (small ones get inlined by Vite). Two gotchas: `infoamazonia.png` has a **baked dark `#191E23` background** (no alpha), so the footer bottom bar must stay `bg-base` for it to blend; `codesinfo.png` is transparent. Remaining UI glyphs (workshop calendar, checkbox check, play/close, chevrons, WP step section) use **lucide-react** / inline SVG (`JeoMark`, `WordPressIcon`).

2. **The design system is split between two files, not inline.** Theme tokens — the `brand` teal palette, `ink`/`base`/`panel`/`card-*`/`footer` background colors, `display`/`sans` fonts, and named keyframes/animations — live in `www/tailwind.config.js`. Reusable component classes (`.btn-brand`, `.btn-ghost`, `.section-shell`, `.eyebrow`) and base styles live in `@layer` blocks in `www/src/index.css`. Use these tokens/classes instead of hardcoding hex values or repeating button/container markup.

### Decisions worth preserving (don't regress)

These are choices made and reviewed in response to feedback. Treat changing them as a fresh proposal, not a "fix".

- **No particle/constellation canvas overlays.** A mouse-reactive particle network was tried over Hero and Recursos and explicitly rejected ("disconnected"). Don't reintroduce a canvas dot-network without asking first.
- **The Hero scroll-cue chevron is centered with auto margins, not a transform** (`absolute inset-x-0 mx-auto w-max`). Don't switch it back to `left-1/2 -translate-x-1/2`: Framer Motion animates its `y` via inline `transform`, which clobbers a `translateX(-50%)` and shifts it off-center (most visible on mobile). It also fades out (`opacity`) once `scrollY > 100` and back in near the top.
- **The Hero background is a looping muted video** (`hero-background.mp4`), autoplay + loop + `playsInline`, with `hero-bg.jpg` as the `poster` so the still shows until the video plays. Under `prefers-reduced-motion` the Hero renders only the static poster `<img>` (no video). This replaced the earlier `ParallaxImage` hero background — don't put `ParallaxImage` back in the Hero; it now lives only in `FeaturesSection`.
- **`JeoMark` is the real Figma "J" (node `208:407`)** — three nested white strokes with decreasing opacity plus a top bar, on a `0 0 27 47` viewBox. An earlier hand-drawn "fluted columns" version was rejected as off-brand. `public/favicon.svg` uses the same paths centered on a `#12181d` rounded square. The J mark stays code; only the wordmark beside it is the exported SVG.
- **The favicon is *not* exported from Figma node `1:2`.** That node turned out to be the full design-system artboard (~5000×3500), not an icon. The favicon is built from the J mark above. Don't try to "fix" it by re-exporting `1:2`.
- **The Hero "JEO BRAINS" wordmark is the Figma SVG export** (`jeo-brains-wordmark.svg`, node 187:777), sitting next to the `JeoMark` J pillar — it is **no longer rendered as live text**. The SVG bakes in the design's white logotype with the teal "AI" echo (the highlighted "AI" cue is preserved as vector, not a `text-brand` span anymore). Re-export from Figma rather than re-typing it as text.
- **The footer "hacklab/" logo is the Figma SVG export** (`hacklab-logo.svg`, node `I187:710;108:565`) — white "hacklab" with a teal `/`, no longer a styled text span. Keep it as the SVG asset for brand fidelity.
- **`ParallaxImage` scale values are intentional.** Recursos uses `range=22` with `scale=1.15` / `trailScale=1.24`. The scales keep the parallax offset from ever revealing image edges — if you change `range`, raise the scales accordingly. The trail opacity is driven by pointer velocity (via `useVelocity`) on purpose: invisible at rest, fades in only while the mouse is moving. Don't replace it with a constant opacity.
- **`Header` reveals at `scrollY > innerHeight * 0.5`** (≈50% of the hero), slides down on a spring, and is `pointer-events-none` when hidden. `scroll-padding-top: 5rem` in `index.css` keeps anchor jumps clear of it — don't remove that rule when adding nav links.
- **Section layouts mirror Figma V2 exactly** — these aren't bugs:
  - `WhySection`: heading in the left column (right-aligned on desktop via `lg:text-right`) and **sticky** on desktop so it frames the four `→ TITLE` rows on the right as they scroll. The sticky lives on a plain grid-item wrapper `<div className="lg:sticky lg:top-24">`, *not* on the animated `Reveal` (its entrance transform would fight the sticky offset); the grid keeps `items-start`. Each pain row is a 2-card pair (Atualmente / Com JEO BRAINS) — four pairs, not 2 or 3.
  - `FeaturesSection`: five cards in a 2-column grid. Each card's Figma icon **floats ~50% above the card's top edge** (no box, transparent — the "vazado" effect): `<img>` absolutely positioned `-top-9 left-7 h-[60px]`. The icon grows **upward/outward** with its bottom anchored inside the card's uniform `p-7` padding, so resizing it never disturbs card spacing (don't add extra top padding — equal padding on all sides is intentional). The grid uses `gap-y-14` so floating icons clear the row above. The lone 5th card is **centered on desktop** via `md:col-span-2 md:mx-auto md:w-[calc(50%-0.75rem)]` (so it doesn't leave a gap). Each card has a single **"Ver Documentação"** button linking to its `docUrl` — the old "Vídeo tutorial" button was removed (videos aren't ready); don't re-add it without new content.
  - `WorkshopsSection` ("Participe das oficinas"): two cards with a **vertical teal gradient** (`bg-gradient-to-b from-brand-darkest via-brand-darkest/30 to-base`), calendar icon + "OFICINA N" (teal), centered title/body, "Público:" line, and a full-width "Inscrever-se" button — matching Figma.
  - `Footer` (mirror Figma node 158:331): logo (J mark `h-20` + "JEO" `text-5xl`) and nav are **grouped and centered** (not edge-to-edge). The three partner logos are sized by their **Figma height ratio** ≈ 40:28:18 → `infoamazonia` and `codesinfo` at `h-7`, `hacklab-logo.svg` at `h-[11px]` (it's a tightly-cropped SVG, so it must be much shorter than the padded PNGs or it looks oversized — the earlier bug).
  - `WordPressSection` (mirror Figma node 229:422): the grouping box uses a **vertical teal→gray gradient** (`bg-gradient-to-b from-brand to-muted-3`) running a slow looping pan (`animate-gradient-pan` + `bg-[length:200%_200%]`, `[animation-duration:14s]` — keep it subtle). Heading + "PASSO N" labels are `font-condensed` and dark (`text-ink`); the big step numbers are condensed `text-5xl/6xl`. The four step cards are **equal height** (grid stretches; each is `flex h-full flex-col` with the body box `flex-1`) and each body box is a dark gradient `bg-gradient-to-b from-card-dark to-base` with a teal **top** border (`border-t-2 border-brand`).
  - `ReadySection`: the real `editor-print.png` screenshot doubles as a **play button** (lucide `Play` + pulse ring) that opens a responsive video modal playing `print-animado.mp4` (lucide `X` to close, Escape closes, body scroll locks while open). Not a hand-built editor mock (an earlier `EditorMock.jsx` was deleted).
  - `Footer` bottom bar is `bg-base` so `infoamazonia.png`'s baked dark background blends.
- **No test runner / linter is being added.** Verify visually via `npm run build` + browser, not `npm test`/`npm run lint`.

### Animation

Motion is opt-in per element via Framer Motion (`Reveal`, `whileHover`, `whileInView`, gradient/float keyframes). `Reveal` and other animated components call `useReducedMotion`, and `index.css` neutralizes animations under `prefers-reduced-motion` — keep new motion behind the same guard.
